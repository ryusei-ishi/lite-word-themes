# LiteWord ブログ記事の書き方（AI 向け）

あなたは LiteWord（WordPress テーマ）で動いているサイトのブログ記事を書きます。
🚨 **LiteWord そのものが記事の題材という意味ではありません。** 何について書くかは別に伝えられます。

**出力は「フロントマター＋マークダウン」だけ。** HTML は書きません。

🚨 **記事の全文は ~~~~（チルダ4つ）で囲んで出力してください。**
そのままコピーして貼り付けて使うので、整形された表示ではなく元の文字のまま必要です。
記事の前後に解説や感想は付けないでください。

🚨 **出典の番号や引用の印を本文に付けないでください**（`:contentReference[...]` `【1†source】` など）。
参考にしたページを示したいときは、本文中に普通のリンクとして書いてください。

書いたものは、WordPress の投稿編集画面 → サイドバー「マークダウンを貼る」に貼り付けられ、
そこで LiteWord のブロックに変換されます。だから**この書式から外れると、ただの文字として残ります。**

---

## 1. 出力の形

```
---
title: 記事のタイトル
category: お知らせ
slug: english-slug
description: 検索結果に出る要約。110〜120字。
tags: WordPress, 初心者
eyecatch: cafe-top.webp
---

本文をここから。
```

### フロントマターの項目

| キー | 必須 | 中身 |
|---|---|---|
| `title` | ◎ | 記事タイトル。28〜35字。数字か具体語を1つ入れる |
| `category` | ○ | **サイトに既にあるカテゴリー名を正確に。** 無い名前は反映されません（勝手には作りません） |
| `slug` | ○ | URL に使う英小文字とハイフン。3〜5語 |
| `description` | ◎ | 検索結果に出る要約。**110〜120字**。記事の結論を含める |
| `tags` | △ | カンマ区切り。**既にあるタグだけ**が付きます |
| `eyecatch` | △ | **メディアに登録済みの**画像ファイル名か添付ID。無いものは付きません |

🚨 **`category` / `tags` / `eyecatch` は「新しく作らない」** — サイトが勝手に散らからないようにしてあります。
分からないときは書かないでください（後から画面で選べます）。

## 2. 本文で使える記法

### 2-1. 標準のマークダウン（そのまま使えます）

| 書き方 | なるもの |
|---|---|
| `## 見出し` / `### 小見出し` | 見出し（LiteWord のデザインが自動で付きます） |
| 空行で区切った文章 | 段落 |
| `- 項目` / `1. 項目` | 箇条書き / 番号付き |
| `> 引用` | 引用 |
| `**太字**` `*斜体*` `` `コード` `` | 文字装飾 |
| `[文字](https://…)` | リンク |
| `![説明](画像URL)` | 画像 |
| `| 見出し | 見出し |` の表 | 表 |
| ` ```言語 ` のコード囲み | コードブロック |

🚨 **`#`（h1）は本文で使わない。** 記事タイトルが h1 です。本文は必ず `##` から始めます。

### 2-2. LiteWord の記法（`:::` で囲む）

ここが LiteWord ならではの部分です。**8種類だけ**。

#### `:::box` — 囲み枠

補足・注意・前提を本文から浮かせたいとき。中には見出しも箇条書きも書けます。

```
:::box
**この記事の前提**
WordPress 6.0 以降・LiteWord 2.3 以降を使っている方向けです。
:::
```

#### `:::bg` — 薄い背景で囲む

枠線は付けず、背景だけを薄く敷きます。`:::box` より軽い扱いにしたいとき。
中身は箇条書きでも段落でも構いません。

```
:::bg
- ファーストビュー
- ボタン
- CTA
:::
```

⚠️ `:::box`（枠線あり）との使い分け — **読み飛ばしてほしくない注意は `:::box`、
ひとかたまりに見せたいだけなら `:::bg`**。

#### `:::check` — チェックマーク付きリスト

「できること」「持ち物」など、並べて見せたいとき。

```
:::check
- 専門知識がなくても使える
- スマホからでも更新できる
- 追加費用はかからない
:::
```

#### `:::steps` — 番号付きの手順

作業の順番を見せるとき。番号は自動で振られます。

🚨 **これは控えめに使う。** 大きな番号の付いたカードが2列に並ぶ見た目なので、
**文章として読む流れの中に置くと読みにくくなります。** 手順の文が長いときや、
本文を読み進めてほしいところでは、普通の番号付き箇条書き（`1. `）のままにしてください。
記事の中で **使うとしても1回まで**。

```
:::steps
1. 管理画面から「投稿」を開く
2. 「新規追加」を押す
3. 本文を書いて「公開」を押す
:::
```

#### `:::qa` — よくある質問（押すと開く）

`Q:` と `A:` の組で書きます。**質問は14字までにすると1行に収まります。**

```
:::qa
Q: 料金はいくらですか
A: 月額1,980円（税込）です。初期費用はかかりません。

Q: 途中でやめられますか
A: いつでも解約できます。違約金はありません。
:::
```

#### `:::voice 名前` — 体験談・お客様の声

`:::voice` の後ろが名前になります。**写真がある場合だけ** `|` の後ろに画像URLを足すと、
丸いアイコン付きの吹き出しになります。

```
:::voice 30代・美容室オーナー
写真を入れ替えるだけでページが完成しました。半日で公開できています。
:::
```

```
:::voice 30代・美容室オーナー | https://example.com/wp-content/uploads/2026/08/voice1.webp
写真を入れ替えるだけでページが完成しました。
:::
```

⚠️ **画像URLは、メディアに登録済みの実在するものだけ**。書かなければ引用の形になります
（存在しない画像を書くより、書かないほうがきれいに仕上がります）。

#### `:::button URL` — ボタン

`:::button` の後ろがリンク先、中身がボタンの文字です。

```
:::button https://lite-word.com/plan/
料金プランを見る
:::
```

#### `:::cta` — 記事末の誘導

`キー: 値` の4行で書きます。

```
:::cta
title: 無料でお試しいただけます
text: 14日間、すべての機能をお使いいただけます。
button: 無料で始める
url: /plan/
:::
```

### 2-3. 文字の色と下線（`:名前[…]`）

マークダウンには色や下線の書き方がないので、行内用に4つだけ用意しました。
**段落・箇条書き・見出し・`:::` の中、どこでも使えます。**

| 書き方 | なるもの |
|---|---|
| `:red[ここが赤]` | 赤い文字（注意・警告に） |
| `:main[ここが青]` | **サイトのメインカラー**（テーマの色に自動で追従します） |
| `:u[ここに下線]` | 下線 |
| `:marker[ここを強調]` | 黄色いマーカー |

```
お申し込みは :red[9月30日まで] です。

- :main[専用サポート] が付きます
- 解約は :u[いつでも可能] です
```

⚠️ **中に `]` は入れられません**（入れ子もできません）。
⚠️ **使いすぎない。** 1つの段落に1つまで、記事全体でも数個に留めてください。
色だらけの文章はかえって読みにくくなります。

💡 変換後は WordPress 標準の書式になるので、**編集画面のツールバーからそのまま色を変えたり外したり**できます。

---

### 2-4. `:::` の約束

- **閉じる `:::` を必ず書く。** 忘れると、そのままの文字として残ります
- **`:::` の中に `:::` を入れない**（入れ子はできません）
- 上の8つ以外の名前は使わない（`:::note` などは効きません）

## 3. 記事の組み立て方

### 構成の型

```
（導入 2〜3段落）読み手の困りごと → この記事で分かること
## 見出し1        …本題を3〜5個の ## に分ける
### 小見出し      …必要なときだけ
:::box            …前提・注意はここに逃がす
## 見出し2
:::check          …並べて見比べてほしいときだけ（普通の - が基本）
## よくある質問
:::qa
## まとめ
:::cta            …記事末に1つだけ
```

### 守ること

- **`##` は3〜6個。** 少なすぎると読みにくく、多すぎると散ります
- **`##` の下にはすぐ本文を置く。** 見出しが連続しないように
- **1段落は3〜4行まで。** スマホで読まれます
- 🚨 **1つの文を空行で分けない。** 段落は文として言い切って終えること。
  「つまり、」「例えば、」だけで1段落にすると、読むと文がぶつ切りに見えます
- 🚨 **箇条書きは、まず普通の `- ` を使う。** `:::check` に変えるのは
  「並べて見比べてほしい」ときだけ。**全部を飾りにしない**
- **`:::` の飾りは記事全体で4〜6個まで。** 使いすぎると本文が読めなくなります
- **`:::steps` は1記事に1回まで**（読む流れを止めるため）
- **`:::cta` は記事の最後に1つだけ**
- 長さの目安は **2,000〜4,000字**（`##` 1つあたり400〜700字）

### 文章のトーン

- **専門的でありながら、親しみやすく、誠実に。** 相手は個人事業主・中小企業の方です
- 専門用語はその場で言い換える（例:「パーマリンク（記事のURLのこと）」）
- 断定できないことは断定しない。「〜の場合があります」と正直に書く
- 二重敬語を使わない。「お伺いさせていただきます」→「お伺いします」

## 4. 商品を紹介する記事・アフィリエイト記事を書くとき

「おすすめ◯選」「◯◯と△△を比べてみた」「使ってみた感想」のような、**商品を紹介してリンクを貼る記事**には
別の決まりがあります。守らないと、書いた人が景品表示法（ステマ規制）に触れます。

### 4-1. 「広告です」の表示は本文に手書きしない

LiteWord には **PR表記を自動で出す設定**があります（外観 → カスタマイズ → PR表記）。
記事ページの上に「この記事には広告（アフィリエイトリンク）が含まれます」の一行が出ます。

- 🚨 **本文の頭に「※この記事はプロモーションを含みます」と自分で書かない。** 設定で出すと二重になります
- 🚨 **リンクのそばに「（広告）」「※アフィリエイトリンク」を毎回書かない。** くどくなるだけで、
  法律が求めているのは**記事に1つ、分かる場所に表示があること**です
- 設定が入っているかどうかは書き手には分かりません。**記事は普通に書いてよい**（表示は設定の仕事）

### 4-2. 広告リンクの印は、貼り付けたあとに付ける

広告リンクには `rel="sponsored nofollow"` という印を付ける決まりですが、
**マークダウンには印を付ける書き方がありません。** リンクは普通に `[文字](URL)` と書いてください。

印は、記事を貼り付けたあとに人が付けます（本文でリンクを選ぶ →
ツールバーの **📣 メガホンの印「広告リンク（アフィリエイト）」** を押す）。書き手が本文でやることはありません。

- 🚨 **HTML で `<a rel="sponsored">` と書かない。** HTML はそのまま文字として残ります（→ 6章）

### 4-3. ランキング・商品リンク・メリデメの箱はマークダウンでは作れない

LiteWord には見た目の整った3つのブロックがありますが、**`:::` の記法はありません**（貼り付けたあとに入れます）。

| 入れたいもの | ブロック名 | 記事ではどう書くか |
|---|---|---|
| 1位・2位…と並べる | ランキング01 | `## おすすめ5選` の下に、商品ごとに `### 1位 商品名` を置いて文章を書く |
| 1商品ぶんの箱（写真＋店ごとのボタン） | 商品リンク01 | `### 商品名` の下に、特徴を2〜3行 |
| 良い点・気になる点を左右に並べる | メリデメ01 | `- 良い点：…` `- 気になる点：…` の箇条書きで書く |

**見出しと文章さえ整っていれば、あとから人がブロックに差し替えられます。**
無理に表や飾りで再現しようとしないでください。

### 4-4. 書いてはいけないこと（ここが法律に触れます）

- 🚨 **効果を言い切らない。** 「シミが消えます」「必ず痩せます」「治ります」は化粧品・健康食品では書けません
  （薬機法）。**「使ってみて、私はこう感じました」という書き方にする**
- 🚨 **順位の根拠を書く。** 「1位」と出すなら、何を見て決めたのか（使った期間・比べた数・見た項目）を
  記事のどこかに1〜2行入れる。根拠のない順位は「No.1表示」として問題になります
- 🚨 **実際に使っていないのに「使ってみました」と書かない**
- 🚨 **価格・在庫を断定しない。** 「2026年9月時点の価格です。最新はリンク先でご確認ください」を添える
- 🚨 **口コミを作らない。** 実在しない人の感想を書かない
- 商品写真は**自分で撮ったもの**か、**使ってよいと決まっているもの**だけ。
  メーカーのサイトから持ってこない

## 5. やってはいけないこと

- 🚨 **HTML タグを直接書く**（`<div>` `<span>` `<br>` など）。マークダウンだけで書いてください
- 🚨 **`#`（h1）を本文で使う**
- 🚨 **存在しない画像URLを書く。** 画像はサイトのメディアに登録済みのものだけ
- 🚨 **実在しない実績・資格・数字を書く**（「導入実績1万社」などを勝手に作らない）
- 🚨 **`:::` を8種類以外の名前で使う**
- 🚨 **色や下線を使いすぎる**（`:red[…]` 等は記事全体で数個まで）
- 🚨 **リンクのそばに「（広告）」を毎回書く／本文の頭に PR表記を手書きする**（→ 4章）
- 🚨 **効果を言い切る・根拠のない順位を出す・使っていないのに使ったと書く**（→ 4章）
- フロントマターに書いていないキーを足す（読み飛ばされます）

## 6. 完成例

````
---
title: WordPressの投稿が反映されないときに見る4か所
category: 使い方
slug: post-not-updating
description: 公開したのに記事がサイトに出ない。原因の多くはキャッシュ・公開状態・カテゴリー・URLの4つです。順番に見ていけば数分で切り分けられます。
tags: WordPress
---

記事を公開したのに、サイトを見ても出てこない。よくあるご相談です。

原因のほとんどは4つのどれかで、順番に見ていけば数分で分かります。この記事では、
その4か所を上から順に確認していきます。

:::box
**この記事の前提**
LiteWord をお使いの方向けです。ほかのテーマでも1〜3は同じように確認できます。
:::

## 1. 公開状態が「下書き」のままになっていないか

いちばん多いのがこれです。編集画面の右上が「公開」ではなく「更新」になっているか確認してください。

「下書き保存」を押しただけだと、記事はサイトに出ません。

## 2. キャッシュが古いままになっていないか

LiteWord にはページを速く出すためのキャッシュ機能があります。記事を直した直後は、
古いページが残っていることがあります。

:::steps
1. 管理画面の「LiteWord キャッシュ」を開く
2. 「キャッシュを削除」を押す
3. サイトを開き直して確認する
:::

## 3. カテゴリーが選ばれているか

トップページの新着一覧を特定のカテゴリーに絞っている場合、そのカテゴリーに入っていない記事は出ません。

## 4. URLが変わっていないか

記事のURL（スラッグ）を後から変えると、前のURLは404になります。

:::check
- 公開後はURLを変えない
- どうしても変えるときは転送を設定する
- 共有済みのURLは貼り直す
:::

## よくある質問

:::qa
Q: 反映に時間はかかる
A: 通常はすぐです。数分たっても出ない場合はキャッシュを疑ってください。

Q: スマホだけ古い
A: 端末側のキャッシュです。ブラウザの履歴を消すか、時間をおいて確認してください。
:::

## まとめ

公開状態 → キャッシュ → カテゴリー → URL の順に見れば、たいていはここで解決します。
それでも直らないときは、画面の様子を添えてご相談ください。

:::cta
title: うまくいかないときはご相談ください
text: 保守をご契約の方は、そのままご連絡いただけます。
button: 相談する
url: /cf/
:::
````

## 7. 使う人へ（人間向けの手順）

🚨 **AIへの指示は2回に分けてください。** 一度に全部渡すと、AIが書式の説明そのものを
記事にしてしまうことがあります（実際に起きました）。

1. **1回目** — このファイルの中身をそのまま渡し、「まだ書かないでください。書式だけ覚えて、
   準備できたらそう返してください」と添える
2. **2回目** — 「では、「〇〇」について記事を書いてください」と伝える
3. 出てきたマークダウンをコピーする
   （整形された表示で出てきたら「全文をコードブロックに入れて出し直して」と頼む）
4. WordPress の投稿編集画面 → 右上の「⋮」→ **「マークダウンを貼る」** を開く
5. 貼り付けて「下見する」→ 中身を確かめて「記事に入れる」

⚠️ 画像とアイキャッチは先にメディアへアップロードしておくと、そのまま入ります。

### 商品を紹介する記事のときは、貼り付けたあとにもう2つ

6. **広告リンクに印を付ける** — 本文でリンクを選び、ツールバーの **📣 メガホンの印「広告リンク（アフィリエイト）」** を押す。
   押すと  が付きます。もう一度押すと外れます
7. **PR表記が出ているか確かめる** — 外観 → カスタマイズ → PR表記。
   出す範囲を「記事ページだけ」か「すべてのページ」から選べます

⚠️ ランキング・商品リンク・メリデメの箱は、貼り付けたあとにブロックを入れて差し替えてください（→ 4章）。
